# 3D Model Files

Place your 3D model files in this directory:

- `ESK1.obj` - The 3D object file
- `ESK1.mtl` - The material file with texture references
- Any texture image files referenced by the MTL file (e.g., `.jpg`, `.png`)

## File Structure Example:
```
models/
├── ESK1.obj
├── ESK1.mtl
├── textured_output.jpg
└── README.md
```

The 3D viewer will automatically load and display these files with proper textures and materials.
